🤖 MOKAMBO — AI Chatbot with 3 Personalities

MOKAMBO is a Generative AI chatbot built with Python, Streamlit, LangChain, and Mistral AI.

The idea is simple: instead of interacting with an AI that always responds in the same way, MOKAMBO lets the user choose between three different personalities, each with its own tone and behavior.

«The personalities are implemented through system prompts that guide how the Mistral model responds.»

---

⚙️ How It Works

The user first selects one of the three personalities.

Each personality has a dedicated system prompt that defines the AI's behavior.

The selected personality is then passed to the Mistral model along with the conversation history.

User
  ↓
Select Personality
  ↓
System Prompt
  ↓
LangChain Message History
  ↓
Mistral AI
  ↓
Personality-Based Response
  ↓
Streamlit Chat UI

MOKAMBO uses Streamlit Session State to maintain the conversation during the current session.

🔐 API Key Security

The Mistral API key is not stored inside the GitHub repository.

For local development, environment variables can be used.

For Streamlit deployment, the API key is stored securely using Streamlit Secrets.

Example:

MISTRAL_API_KEY = "your_api_key_here"

The application accesses it at runtime:

api_key=st.secrets["MISTRAL_API_KEY"]

The actual API key should never be committed to GitHub.

---

⚡ Model Initialization

MOKAMBO uses Streamlit's "@st.cache_resource" to avoid unnecessarily recreating the model on every Streamlit rerun.

@st.cache_resource
def load_model():
    return ChatMistralAI(
        model="mistral-small-2506",
        temperature=0.9,
        api_key=st.secrets["MISTRAL_API_KEY"]
    )

model = load_model()

This helps reduce unnecessary model initialization and can improve the application's responsiveness after Streamlit reruns.

💻 Run Locally

1. Clone the repository

git clone https://github.com/aniket-andyy/MOKAMBO-AI.git
cd MOKAMBO-AI

2. Create a virtual environment

python -m venv venv

Activate it on Windows:

venv\Scripts\activate

3. Install dependencies

pip install -r requirements.txt

4. Add your API key

Create a ".env" file:

MISTRAL_API_KEY=your_actual_api_key

Do not upload ".env" to GitHub.

Make sure ".env" is included in ".gitignore".

5. Run the application

streamlit run UIchatbot.py

The application will open in your browser.
